# Contributing / Repository Governance

We've set up the team repository with the following rules, in line with the Master Project Brief:

- One shared repo: <https://github.com/ArmandErasmus/SEN-381.git>
- Nobody can push directly to the main branch, and every change must go through a pull request.
- A pull request needs approval from another member and cannot be approved by the person who made the pull request.
- If new commits are added to an open pull request, old approvals are cleared and it needs to be reviewed again.
- No passwords, keys or credentials are committed. We use a `.env.example` file instead of a real one.
- Every pull request follows a short template asking what changed, why, and how it was tested.
